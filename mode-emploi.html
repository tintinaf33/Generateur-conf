Générateur de configurations — mode d'emploi

Un outil pour transformer un modèle de configuration en config prête à coller, en ne remplissant que les variables. Aucune installation, aucun envoi de données : tout se passe dans le navigateur, sur ton poste.

Démarrer

Double-clique sur le fichier generateur-configurations.html : il s'ouvre dans le navigateur. Il fonctionne hors ligne et rien ne sort de la machine. On peut le poser sur un partage réseau ou l'envoyer par mail — tant que le fichier reste entier, il marche partout.

Le principe

Un modèle est un texte de config dans lequel les valeurs à personnaliser sont écrites entre doubles accolades, par exemple {{ nom du site }}. L'outil repère ces variables tout seul et crée un champ pour chacune. Le modèle « Interface P2P — Junos » est déjà pré-chargé.

Les quatre usages

Une config Onglet Une config : tu remplis les champs à gauche, la configuration se génère à droite en direct. Bouton Copier.
En lot (depuis Excel) Onglet En lot : tu sélectionnes tes colonnes dans Excel et tu les colles (une config par ligne). L'ordre des colonnes attendu s'affiche au-dessus de la zone. L'outil génère une config par ligne, chacune copiable ; boutons Tout copier et Télécharger .txt.
Lien P2P — un lien Onglet Lien P2P, mode Un lien : tu renseignes les deux routeurs, leurs interfaces, l'@IP côté A et les deux MEP. L'outil génère les deux bouts du lien d'un coup : il calcule l'@IP du voisin (la paire du /31), inverse les MEP source/remote entre les deux côtés et applique la même maintenance-association des deux côtés.
Lien P2P — plusieurs liens Même onglet, mode Plusieurs liens (Excel) : tu colles une liste de liens depuis Excel et l'outil génère les deux bouts de chaque lien en une fois.

Gérer les modèles

En haut, le menu déroulant liste les modèles. À côté :

  • ✎ Modifier — changer le nom ou le contenu du modèle courant.
  • ＋ Nouveau — créer un modèle : colle ta config et mets {{ }} autour de tout ce qui doit devenir un champ.
  • ⧉ Dupliquer et 🗑 Supprimer (deux clics pour confirmer).

Ça fonctionne pour n'importe quel équipement, pas seulement le modèle Junos.

Partager les modèles à l'équipe

Les modèles sont enregistrés dans le navigateur de chacun. Pour les diffuser : une personne clique ⬇ Exporter (un fichier .json), l'envoie à l'équipe, et chacun fait ⬆ Importer. Tout le monde a alors le même jeu de modèles.

Les garde-fous

  • Validation : un champ @IP ou MEP mal rempli passe en rouge (IP non valide, MEP non numérique).
  • Détection de collisions : dans le lot de liens, un bandeau orange signale une @IP utilisée deux fois ou une interface réutilisée sur le même routeur, avec les lignes concernées.
À vérifier avant la prod. Fais toujours un essai avec un lien connu pour confirmer que l'affectation A/B et le choix de la maintenance-association correspondent à votre convention. L'outil accélère la saisie mais ne remplace pas la relecture avant de pousser sur un routeur.

Outil interne — fonctionne hors ligne, aucune donnée transmise. Pour toute évolution (rollback, registre d'adressage, nouveaux modèles), voir l'auteur de l'outil.
